# Changelog

## v0.1.0 (2026-10-03)

First public release. Grows the Second Brain Starter Kit (the `raw/` and `wiki/` core from the guide) into a full constitution.

- `CLAUDE.md` constitution template: owner, load order, which document wins, three memories, write rule, one writer per store, hard rules, logging, escalation, the fixed point.
- `instructions.md` preferences template.
- Skills: `extend-toolkit`, `ingest`, `lint-brain`, with `skills/_schema.md` and a catalogue. Claude Code wrappers in `.claude/skills/`.
- `log/` with schemas for runs, decisions and feedback.
- `decisions/` with a memo template, four stance forms and dissent kept word for word.
- Docs: the three memories, why plain files, running with a team, plugging in a room.
- Synthetic examples: an ingest run before and after, and a resolved decision memo.
- Prompts for Claude Code, chat projects, and agents that read `AGENTS.md`.
