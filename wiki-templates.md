# Wiki templates

Reference shapes. The agent writes these files itself. Use these to check its work, not to hand-type them.

## A good page

```
# [Page Title]

## Summary
One paragraph. What this is, and why it matters.

## Key Concepts
- [[Related-Page]]: how it connects
- [[Another-Page]]: how it connects

## Main Content
The synthesis. What you actually know now, in clean prose.
Each claim tagged fact (with its source) or assumption.

## Sources
- raw/the-file-this-came-from.md
```
